# Space travel service

A prototype for an imaginary GOV.UK service where people can book a trip to the Moon or Mars. Built with the GOV.UK Prototype Kit and Design System for the Mercator Digital interaction designer exercise.

## View the prototype

https://space-travel-service-y7ua.onrender.com/

The prototype is password protected. I've sent the password separately.

## The journey

1. Start page
2. Where do you want to travel?
3. Mars only: Can you travel for up to 3 years?
   - No: "You cannot travel to Mars" page, with a link to choose a different destination
4. What is your full name?
5. What is your address?
6. Check your answers
7. Booking confirmed
